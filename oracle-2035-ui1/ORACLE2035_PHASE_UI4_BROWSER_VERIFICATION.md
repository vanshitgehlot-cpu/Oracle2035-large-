## Live journey

The local app was started on port 3000 and opened in Chromium. The existing landing page rendered in the new dark-first theme, with the obsidian canvas, grid atmosphere, warm editorial serif typography, cobalt action color, and dark structural preview visible without runtime errors.

The existing intake journey was exercised with its seeded local draft through Decision Core, Financial Reality, Execution Capacity, Commitments, Evidence & Baseline, Review, and Execute Analysis. Selecting Financial Exposure entered Focus Mode, receded the surrounding nodes, exposed the existing runway, monthly net cash, post-commitment capital, contributing variables, active assumption, state, and provenance action, and did not issue a new request.

## Visual findings

The landing page now presents as a dark spatial intelligence instrument rather than a light SaaS dashboard. The analysis surface now uses an obsidian canvas, quiet grid, luminous but restrained rings and links, dark instrument surfaces, and green/amber semantic states. The Decision Core remains usable as an accessible button list because each node is a native button with `aria-pressed`; the inspector provides a text equivalent to the spatial view.

The app console contained the standard React DevTools informational message only. The build retained the pre-existing `crypto` browser-externalization warnings and the pre-existing large-client-chunk warning; no new warning class was introduced by UI-4.

## Scope note

This verification covered the live landing, intake, analysis dossier, and Decision Core interaction. The CSS includes mobile fallbacks for the spatial surface below 900px and 620px; the existing test suite continued to pass its mobile layout and accessibility contracts.
